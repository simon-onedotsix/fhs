# File modification boundary

Only create, edit, delete, or rename files inside `pages/living/` in this repository.

Do not modify any file outside `pages/living/`, including project configuration,
dependencies, documentation, tests, and this `CLAUDE.md` file. Do not write
generated files, logs, or temporary files elsewhere in the repository.

You may read files outside `pages/living/` when needed for context, but if a task
requires changes outside `pages/living/`, stop and ask for permission instead
of making those changes.

This file documents the boundary for Claude Code; it is an instruction, not an
OS-enforced security restriction.
